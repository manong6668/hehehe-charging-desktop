禾禾充电桩桌面客户端，提供 Windows x64 EXE、Windows x64 MSI、macOS Apple Silicon DMG 和 macOS Intel DMG。

该预览版使用独立的应用标识、数据目录、充电桩图标和下载入口。MSI 卸载范围已限定到本应用资源。

安装包当前为未签名预览构建。Windows 可能显示发布者或 SmartScreen 提示，macOS 构建尚未配置 Developer ID 与公证。正式签名需由维护者配置对应证书。

本版本在浏览器中打开本项目仓库的 Releases 下载页。仓库公开发布后，安装包可直接下载。应用安装之后，可按需安装 Agent 并添加自己的 API 地址及密钥。
